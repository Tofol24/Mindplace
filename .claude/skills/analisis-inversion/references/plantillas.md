# Plantillas de Output

Todas están pensadas para leerse en móvil. Corto, concreto, sin adornos.

---

## 1. Ficha de Análisis

```
📄 [NOMBRE DEL ACTIVO] ([TICKER])
Horizonte: [corto / medio / largo]    Fecha: [DD/MM/AAAA]

QUÉ ES
[Una frase. Sin jerga. Si no cabe en una frase, no está entendido.]

TESIS — por qué debería valer más
[Máximo 3 líneas. Empieza por "Debería valer más en [horizonte] porque..."]

EN CONTRA — las 2 razones más fuertes para NO entrar
1. [ ]
2. [ ]

DÓNDE ESTÁ EL PRECIO
Actual: [X €]
En su rango: [cerca de máximos / zona media / cerca de mínimos] del último [periodo]
Contexto de tendencia: [alcista / bajista / lateral] en marco [semanal/diario]

INVALIDACIÓN — qué me diría que me he equivocado
[Hecho concreto y comprobable: un precio perdido, un dato que no llega, un cambio en el negocio]

TAMAÑO
Riesgo aceptado: [1%] del capital = [Y €]
Distancia a invalidación: [Z %]
→ Posición: [W €] = [V %] de la cartera

⚠️ RIESGO PRINCIPAL
[El que de verdad puede doler, no el genérico]

📌 QUÉ VIGILAR
[1-3 cosas concretas que cambiarían la lectura]
```

## 2. Entrada de Diario — al ABRIR

Se escribe **antes** de ejecutar la orden. Si se escribe después, no sirve: ya está contaminada.

```
━━━ APERTURA · [DD/MM/AAAA HH:MM] ━━━
Activo: [ ]              Horizonte declarado: [corto / medio / largo]
Entrada: [precio]        Tamaño: [€] ([% cartera])
Invalidación: [precio o hecho]     Riesgo real: [€] ([% cartera])
Objetivo o condición de salida en positivo: [ ]

POR QUÉ ENTRO (3 líneas máximo)
[ ]

QUÉ ME HARÍA SALIR ANTES DE TIEMPO
[ ]

CÓMO ESTOY AHORA (1-5)
Calma: [ ]   Prisa: [ ]   Convicción: [ ]
¿Vengo de una pérdida reciente? [sí / no]
¿He esperado 24h desde que se me ocurrió? [sí / no]
```

El bloque emocional no es decorativo: al revisar el diario a los tres meses, es lo que revela el patrón.
Casi siempre las peores operaciones comparten un "prisa: 5" o un "vengo de una pérdida: sí".

## 3. Entrada de Diario — al CERRAR

```
━━━ CIERRE · [DD/MM/AAAA HH:MM] ━━━
Salida: [precio]      Resultado: [+/- €] ([+/- %])
Tiempo en posición: [ ]   ¿Coincide con el horizonte declarado? [sí / no]

¿SEGUÍ MI PLAN? [sí / no]

CLASIFICACIÓN
[ ] Ganó + seguí el plan      → Buena decisión ✅
[ ] Perdió + seguí el plan    → Buena decisión ✅ (mala suerte, no error)
[ ] Ganó + me salté el plan   → Mala decisión ⚠️ PELIGRO: esto refuerza el mal hábito
[ ] Perdió + me salté el plan → Mala decisión ❌

QUÉ PASÓ REALMENTE
[ ]

¿QUÉ HARÍA IGUAL?
[ ]

¿QUÉ HARÍA DISTINTO?
[Una sola cosa. Concreta y accionable.]
```

**Lo importante del diario no es el resultado, es la columna "¿seguí mi plan?".**
Un método bueno con racha mala sigue siendo un método bueno. Un método malo con racha buena arruina más tarde,
con más dinero dentro.

## 4. Revisión de Invalidación (posición abierta que se mueve en contra)

```
━━━ REVISIÓN · [DD/MM/AAAA] ━━━
Posición: [ ]     Entrada: [ ]     Actual: [ ]     [+/- %]

¿HA CAMBIADO ALGÚN HECHO, O SOLO EL PRECIO?
Hechos nuevos desde la entrada: [ninguno / lista]

¿SE HA ALCANZADO LA INVALIDACIÓN ESCRITA AL ENTRAR? [sí / no]
→ Si sí: se cierra. No se renegocia.
→ Si no: se mantiene el plan, sin añadir ni quitar.

TEST DE LA POSICIÓN LIMPIA
"Si no tuviera esto, ¿lo compraría hoy a este precio?"  [sí / no]
→ Si no, la posición está abierta por inercia.

¿ESTOY PENSANDO EN PROMEDIAR A LA BAJA?
¿Estaba escrito en el plan de entrada? [sí / no]
→ Si no estaba escrito, es rescate emocional. No es estrategia.
```

## 5. Revisión de Cartera

```
━━━ CARTERA · [DD/MM/AAAA] ━━━

POSICIONES
| Activo | € | % cartera | Horizonte | Desde |
|---|---|---|---|---|

REPARTO
Cripto: [%]    Acciones/ETF: [%]    Liquidez: [%]    Otros: [%]
Sobre patrimonio invertible total, la exposición a volátiles es: [%]
¿Coincide con el límite que me marqué por escrito? [sí / no]

CONCENTRACIÓN REAL
¿Qué posiciones suben y bajan a la vez? [ ]
→ Esas cuentan como una sola apuesta, no como varias.

PRUEBA DE ESTRÉS
Si el mercado cae un 40% mañana: pierdo [€]. ¿Puedo sostenerlo sin vender? [sí / no]
¿Qué parte de la cartera NO caería? [ ]

APALANCAMIENTO
Total apalancado: [€]    Precio de liquidación más cercano: [ ]    Distancia: [%]

LIQUIDEZ
Disponible sin vender a pérdida: [€]    Fondo de emergencia intacto: [sí / no]
```

## 6. Revisión Periódica (mensual o trimestral)

```
━━━ REVISIÓN [MES/TRIMESTRE] ━━━

NÚMEROS
Operaciones: [N]    Siguieron el plan: [N] ([%])   ← la métrica que importa
Resultado del periodo: [+/- %]
Comisiones y costes totales pagados: [€]   ← casi siempre sorprende
Referencia pasiva (no hacer nada): [+/- %]
¿Ha merecido la pena la actividad frente a no hacer nada? [ ]

PATRONES
¿En qué situación rompo siempre el plan? [ ]
¿Qué horizonte se me da mejor según el diario? [ ]
¿Cuántas veces cambié de horizonte a media operación? [N]
Mejor decisión del periodo (por proceso, no por resultado): [ ]
Peor decisión del periodo (por proceso, no por resultado): [ ]

UNA SOLA COSA A CAMBIAR EL PRÓXIMO PERIODO
[ ]   ← Una. No cinco. Una regla nueva por periodo, y se cumple.
```
